# 知序 · 考研智能学习 Agent

面向考研英语、法律硕士、思想政治理论的中文学习空间。第一阶段采用 React + TypeScript + Vite，全部学习交互在浏览器本地完成，无需外部 AI 接口、API Key、数据库或后端。

## 运行

需要 Node.js 22.12 或以上版本（当前验证版本：24.19.0）、npm 11。

```bash
npm ci
npm run dev
```

开发服务器默认监听 5173 端口。使用浏览器访问开发服务器即可。

```bash
npm test        # 交互测试
npm run build   # TypeScript 检查及生产构建
npm run preview # 本地检查生产构建，默认 4173 端口
```

部署时将 `dist/` 发布到静态托管服务。没有服务端 API。

## 已实现

- 三科预置多层知识树，节点选择、展开/折叠、搜索和章节跳转。
- 重点标注、掌握状态和个人笔记，自动保存到当前浏览器的 localStorage。
- 按科目管理 PDF；使用 PDF.js 在本地提取文字、显示页数、预览文本和删除资料。
- 主动回忆卡片：先回忆再显示知识要点，支持“还需巩固”与“已掌握”。
- 错题本保存薄弱知识节点，支持移出；并非完整的试题作答/评分系统。
- 基于规则的复习清单：薄弱点 → 重点 → 尚未掌握的叶子节点，每次最多六项。
- 适配桌面与移动屏幕的中文界面。

## 数据与限制

内置知识仅为演示性入门内容，不是完整考研教材或法律意见；请以当年考试大纲和权威教材为准。

PDF 仅提取文字，不生成知识树，不调用 AI；扫描件、OCR、复杂版面还原和加密 PDF 暂不支持。单个文件限制 20 MB，每份只保存前 15 万字符，不保存原始文件。解析文本和学习数据保存在当前浏览器，清除站点数据会丢失记录，不支持跨设备同步。浏览器容量不足或禁用存储时，本次会话仍可使用，但不能保证持久保存；重要内容请另行备份。

“智能背诵”和“复习规划”为本地规则实现，暂不含自适应算法、间隔重复调度、日期日历或 AI 生成。下一阶段可扩展资料到知识节点的关联、OCR、IndexedDB、导入导出、真实题库及可选 AI 适配器。
